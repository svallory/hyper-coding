Initial release of the @hypercli/* packages

- @hypercli/core: Core domain types, configuration, errors, and utilities
- @hypercli/ui: CLI design system with themed output, shortcuts, and help rendering
- @hypercli/kit: Kit lifecycle management for installing and managing generator kits
- @hypercli/gen: Code generation engine with recipe execution and AI integration
- @hypercli/hq: Claude Code session management via tmux
- @hypercli/cli: Unified CLI that composes gen, hq, and kit plugins
