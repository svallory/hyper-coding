# Command Reference

## `hyper hq start`

Start the HQ session — the always-on Claude Code command center.

```bash
hyper hq start
hyper hq start --spawn-mode worktree
hyper hq start --capacity 16
```

| Flag | Description | Default |
|------|-------------|---------|
| `--name` | Custom session name | `hyper-hq` |
| `--spawn-mode` | `same-dir`, `worktree`, `session` | `same-dir` |
| `--permission-mode` | `default`, `acceptEdits`, `plan`, `auto` | `default` |
| `--capacity` | Max concurrent sessions | `32` |

On first run, launches an interactive setup wizard. Shows a welcome banner with config summary, bridge URL, and key commands.

---

## `hyper hq spawn`

Spawn a new Claude session for a project.

```bash
hyper hq spawn my-project
hyper hq spawn my-project --worktree feat-auth
hyper hq spawn my-project --new-worktree feat-login
hyper hq spawn /absolute/path/to/project
```

| Arg/Flag | Description |
|----------|-------------|
| `PROJECT` | Project name or absolute path (required) |
| `--worktree` | Use an existing worktree |
| `--new-worktree` | Create a new worktree via `wt switch -c` |
| `--permission-mode` | Permission mode for the session |
| `--name` | Custom session name |

---

## `hyper hq list`

List available projects and their worktrees.

```bash
hyper hq list
hyper hq list --json
hyper hq list --root /other/path
```

---

## `hyper hq status`

Show running HQ sessions.

```bash
hyper hq status
hyper hq status --json
```

---

## `hyper hq config`

Show current configuration.

```bash
hyper hq config              # Summary view
hyper hq config --json       # JSON output
hyper hq config --path       # File path only
$EDITOR $(hyper hq config --path)  # Open in editor
```

---

## `hyper hq stop`

Stop a session. Defaults to the HQ session.

```bash
hyper hq stop              # Stop hyper-hq
hyper hq stop my-project   # Stop hq-my-project
```

---

## `hyper hq stop-all`

Stop all HQ-managed sessions, including HQ itself.

```bash
hyper hq stop-all
```

---

## `hyper hq attach`

Attach to a tmux session. Useful for seeing the QR code or debugging.

```bash
hyper hq attach              # Attach to HQ
hyper hq attach my-project   # Attach to project session
```

Press `Ctrl+B, D` to detach without stopping the session.
