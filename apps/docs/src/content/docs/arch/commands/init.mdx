## Configuration Priority Levels

Settings are resolved in this order (highest to lowest):

1. **Command-line flags** — always take precedence
2. **Environment variables** — `HYPERDEV_*` variables
3. **Project config** — inherited from parent directories
4. **User configuration** — personal defaults in home directory
5. **System defaults** — built-in fallbacks

```bash
# Layer 1 — command flag (highest priority)
hyper init --template react-lib --ide vscode

# Layer 2 — environment variable
export HYPERDEV_DEFAULT_TEMPLATE=minimal
export HYPERDEV_AI_PROVIDER=anthropic

# Layer 3 — user defaults file
# ~/.hypergenrc.js or ~/.config/hyperdev.config.js
```

## hypergen.config.js Full Schema

Generated by `hyper init` in the project root:

```javascript
// hypergen.config.js
export default {
  // AI Configuration
  aiProvider: 'openai',      // 'openai' | 'anthropic' | 'azure-openai'
  aiModel: 'gpt-4',

  // Template Configuration
  templateSources: [
    'official',
    'community',
    './local-templates'
  ],
  trustThreshold: 8.0,

  // Development Configuration
  qualityGates: {
    security: 'strict',      // 'strict' | 'standard' | 'relaxed'
    performance: 'standard',
    testing: 'required'      // 'required' | 'recommended' | 'optional'
  },

  // IDE Integration
  ide: {
    primary: 'cursor',       // 'cursor' | 'vscode' | 'webstorm'
    extensions: ['hyperdev', 'copilot'],
    settings: {
      aiAssistance: true,
      codeGeneration: true
    }
  }
}
```

## User-Level Config File

```javascript
// ~/.hypergenrc.js
export default {
  defaults: {
    template: "fullstack-saas",
    ide: "cursor",
    aiProvider: "openai"
  }
}
```

## Environment Variables

```bash
# Template defaults
export HYPERDEV_DEFAULT_TEMPLATE=minimal
export HYPERDEV_DEFAULT_IDE=vscode
export HYPERDEV_AI_PROVIDER=anthropic

# Override config path
export HYPERDEV_CONFIG=/path/to/custom/config.js
```

## Project Structure Created

```
my-project/
├── hypergen.config.js      # Project configuration
├── .hyper/                 # HyperDev workspace
│   ├── templates/          # Local templates
│   ├── cache/              # Template cache
│   ├── epics/              # Project epics
│   └── reports/            # Generated reports
├── package.json
├── tsconfig.json
├── .gitignore
├── README.md
└── src/
    ├── components/
    ├── pages/
    ├── api/
    ├── lib/
    └── tests/
```

## Environment-Specific Setup

```bash
# Development environment
hyper init --template saas-app --env development

# Production-ready setup
hyper init --template saas-app --env production --team-config prod.json

# Staging environment
hyper init --template saas-app --env staging
```

## Monorepo Configuration

```bash
# Initialize monorepo root
hyper init --template monorepo-base

# Add workspace packages
hyper init --template api-package --workspace packages/api
hyper init --template ui-package --workspace packages/ui
```

Moon workspace integration (`.moon/workspace.yml`):

```yaml
$schema: 'https://moonrepo.dev/schemas/workspace.json'

projects:
  - 'packages/*'
  - 'apps/*'

hyperdev:
  discovery:
    workspaceRoot: true
    projectTemplates: true
  sharedTemplates: '.hyperdev/shared'
```

## Development Environment Setup Checklist

`hyper init` configures the following automatically:

1. **Package Management** — bun/npm with workspace settings
2. **TypeScript** — `tsconfig.json` with strict configuration
3. **Linting & Formatting** — ESLint, Prettier, and/or Biome
4. **Testing** — Vitest or Jest with coverage reporting
5. **Git Hooks** — Pre-commit hooks for quality checks (via lefthook or husky)
6. **CI/CD** — GitHub Actions workflow stubs
7. **Documentation** — `README.md` and `.hyper/` workspace
