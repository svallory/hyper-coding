# hyper dash

Launches a simple monitoring dashboard so you can see what's going on in your project at a glance.

## Syntax

```bash
hyper dash [options]
```

## Overview

`hyper dash` gives you a quick read on your project without digging through files or running a bunch of status commands:

- **Simple monitoring**: Current project status and progress, all in one place
- **Plan progress**: See how far along each plan is
- **Development status**: Watch build and activity state as you work

<Aside type="note">
  The dashboard is a lightweight overview — it's not a full observability suite, just the basics you actually need day-to-day.
</Aside>

## Basic Views

| View | Description |
|------|-------------|
| `overview` | Project overview and status |
| `plans` | Plan progress tracking |

## Options

| Option | Description | Default |
|--------|-------------|---------|
| `--refresh <seconds>` | Auto-refresh interval | `30` |

## Examples

### Basic Usage

```bash
# Launch dashboard
hyper dash

# Launch with custom refresh rate  
hyper dash --refresh 10
```
