# HyperDev: A Cohesive Development Workflow

HyperDev gives you six tools that map directly to the **Hyper Coding** methodology — a structured approach to AI-assisted development that keeps agents focused, code quality high, and architecture consistent.

## The Six Tools

| Principle | Tool | Purpose |
|-----------|------|---------|
| Deterministic First | `hyper gen` | Code generation with kits, recipes, and Jig templates |
| Tools Integration | `hyper tools` | Set up linters, scanners, AI tools, and architecture tools |
| Engineered Friction | `hyper plan` | Define → Design → Decompose → Develop |
| Reactive Context | `hyper watch` | Always-on agent whisperer |
| Real-time Feedback | `hyper dash` | Real-time monitoring dashboard |
| Session Continuity | `hyper hq` | Claude Code session management |

---

## The Complete Workflow

<Steps>
1. **Generate**

    **`hyper gen`** — Code generation engine for the age of AI.

    Beyond anything you can do with Yeoman and similar tools, hyper templates support **prompt placeholders** that let you combine rule-based deterministic generation with context-dependent AI-driven generation. Starter kits set your agent up for success; tailor-made templates produce consistent, high-quality output.

2. **Set Up Tools**

    **`hyper tools`** — Swiss army knife for your agent.

    Takes care of the tedious work of setting up and configuring all the tools your project needs: linters, formatters, type checkers, dependency scanners, secret scanners, SAST tools, MCP servers, agent definitions, Claude Code commands, complexity scanners, architecture validators, and ADR tooling.

3. **Plan**

    **`hyper plan`** — Every journey starts with deciding where to go.

    Watching Claude Code coordinate 12 parallel agents is impressive — but good results require a good plan. `hyper plan` guides you through four phases:

    - **Define** — Translate business goals into an executable product definition with success metrics
    - **Design** — Create a technical blueprint that sets the rules for agents before any code is written
    - **Decompose** — Break the design into small, actionable tasks with dependencies and acceptance criteria
    - **Develop** — Orchestrate AI agents to execute the task list, shifting review from large code dumps to focused, targeted changes

4. **Watch**

    **`hyper watch`** — The always-on agent whisperer.

    Monitors your agent sessions in real-time. Everything the agent learns from your interactions is captured and stored **locally** in a versioned vector database, giving you persistent context across sessions and keeping agents on track.

5. **Dash**

    **`hyper dash`** — Peek into your agent's brain.

    A real-time dashboard for monitoring and oversight of multi-agent workflows. Track agent activity, task progress, and system health as it happens.

6. **HQ**

    **`hyper hq`** — Claude Code session management.

    Operational tooling for managing your Claude Code sessions — launch, relaunch, and organize sessions without losing context.
</Steps>

---

## How the Tools Work Together

The tools are designed to be used in sequence, each building on the previous:

```
hyper gen      →  bootstrap a project from a kit or template
hyper tools    →  configure linters, scanners, and AI tooling
hyper plan     →  define, design, decompose, then develop
hyper watch    →  monitor agent activity and capture learnings
hyper dash     →  track progress and system health in real-time
hyper hq       →  manage your Claude Code sessions
```

In practice, **gen** and **tools** run at project setup. **plan** is your ongoing feature development loop. **watch** and **dash** run continuously in the background. **hq** is your operational layer for managing sessions.
