# HyperDev Guides & Tutorials

**Hyper Coding** is a structured approach to AI-assisted development: you define clear context and constraints upfront, generate code through templates and recipes rather than free-form prompts, and validate output against automated quality gates before it lands in your codebase. The goal is to make AI generation reliable and repeatable, not just fast.

Practical guides for putting this methodology to work with HyperDev's toolchain. Each one covers a specific scenario---step by step, with real examples and the mistakes worth avoiding.
