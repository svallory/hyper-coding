# Docker Integration

Here's how to run HyperDev inside Docker for consistent environments across dev, staging, and production. The configs below cover everything from a basic single-stage build to multi-stage production setups with layer caching.

## Basic Dockerfile

Create a Dockerfile that includes HyperDev:

```dockerfile
# Dockerfile
FROM node:20-alpine AS base

# Install HyperDev globally
RUN bun add -g @hypercli/cli

# Set working directory
WORKDIR /app

# Copy HyperDev configuration
COPY .hyperdev/ ./.hyperdev/
COPY hypergen.config.js ./

# Development stage
FROM base AS development
COPY package*.json ./
RUN bun install

# Generate development code
RUN hyper gen --all --env development

# Start development server with HyperDev watching
CMD ["sh", "-c", "hyper watch & bun run dev"]

# Production stage  
FROM base AS production
COPY package*.json ./
RUN bun install --production

# Copy source code
COPY . .

# Generate production code
RUN hyper gen --all --env production --optimize

# Build application
RUN bun run build

# Start production server
CMD ["bun", "start"]
```

## Multi-stage Build

Optimize Docker builds with multi-stage approach:

```dockerfile
# Dockerfile.multistage
FROM node:20-alpine AS deps
WORKDIR /app
COPY package*.json ./
RUN bun install --production

FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN bun install

# Install HyperDev
RUN bun add -g @hypercli/cli

# Copy source and generate code
COPY . .
RUN hyper gen --all --env production
RUN bun run build

FROM node:20-alpine AS runner
WORKDIR /app

ENV NODE_ENV production

# Copy built application
COPY --from=builder /app/dist ./dist
COPY --from=deps /app/node_modules ./node_modules
COPY --from=builder /app/package.json ./package.json

EXPOSE 3000

CMD ["bun", "start"]
```

## Docker Compose for Development

Set up a complete development environment:

```yaml
# docker-compose.yml
version: '3.8'

services:
  app:
    build:
      context: .
      target: development
    volumes:
      - .:/app
      - /app/node_modules
      - ./.hyperdev:/app/.hyperdev
    environment:
      - HYPERDEV_ENV=development
      - HYPERDEV_WATCH=true
    ports:
      - "3000:3000"
    command: >
      sh -c "
        hyper watch --detached &&
        bun run dev
      "
```

## Production Docker Compose

Production-ready Docker Compose configuration:

```yaml
# docker-compose.prod.yml
version: '3.8'

services:
  app:
    build:
      context: .
      target: production
    environment:
      - NODE_ENV=production
      - HYPERDEV_ENV=production
    ports:
      - "3000:3000"
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3000/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./ssl:/etc/ssl
    depends_on:
      - app
    restart: unless-stopped
```

## Build Optimization

Optimize Docker builds with caching:

```dockerfile
# Dockerfile.optimized
FROM node:20-alpine AS base

# Install HyperDev (cached layer)
RUN bun add -g @hypercli/cli

FROM base AS deps
WORKDIR /app
# Copy only package files for dependency caching
COPY package*.json ./
RUN bun install --production

FROM base AS builder
WORKDIR /app
COPY package*.json ./
RUN bun install

# Copy HyperDev config first (changes less frequently)
COPY .hyperdev/ ./.hyperdev/
COPY hypergen.config.js ./

# Copy source code
COPY . .

# Generate and build (these steps are cached if code doesn't change)
RUN hyper gen --all --env production --optimize
RUN bun run build

FROM node:20-alpine AS runner
WORKDIR /app

ENV NODE_ENV=production

COPY --from=deps /app/node_modules ./node_modules
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/package.json ./

EXPOSE 3000

CMD ["bun", "start"]
```

## Environment-Specific Builds

Configure different builds for different environments:

```dockerfile
# Dockerfile.env
ARG BUILD_ENV=production

FROM node:20-alpine AS base
RUN bun add -g @hypercli/cli
WORKDIR /app

FROM base AS development
COPY package*.json ./
RUN bun install
COPY . .
RUN hyper gen --all --env development
CMD ["bun", "run", "dev"]

FROM base AS staging
COPY package*.json ./
RUN bun install
COPY . .
RUN hyper gen --all --env staging
RUN bun run build
CMD ["bun", "start"]

FROM base AS production
COPY package*.json ./
RUN bun install --production
COPY . .
RUN hyper gen --all --env production --optimize
RUN bun run build
CMD ["bun", "start"]

FROM ${BUILD_ENV} AS final
```

## Build Scripts

Package.json scripts for Docker integration:

```json
{
  "scripts": {
    "docker:build": "docker build -t myapp .",
    "docker:dev": "docker-compose up --build",
    "docker:prod": "docker-compose -f docker-compose.prod.yml up --build",
    "docker:test": "docker build --target test -t myapp:test .",
    "docker:clean": "docker system prune -f"
  }
}
```

That covers the main Docker patterns — dev containers with hot reload, optimized multi-stage production builds, and environment-specific configurations. Pick the approach that fits your deployment setup.
