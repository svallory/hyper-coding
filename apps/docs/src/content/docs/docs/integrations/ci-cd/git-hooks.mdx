# Git Hooks Integration

Git hooks are the simplest way to make HyperDev validations automatic — no manual steps, no "I forgot to run validate before committing." Here's how to wire them up.

## Pre-commit Hooks

Validate templates before commits:

```bash
#!/bin/sh
# .git/hooks/pre-commit

echo "Running HyperDev pre-commit validations..."

# Validate templates before commit
if ! bun run lint --quiet; then
    echo "❌ Template validation failed. Please fix templates before committing."
    exit 1
fi

# Check for security issues in templates
if ! hyper security-scan --changed-only --fail-on-medium; then
    echo "❌ Security issues found in templates. Please address before committing."
    exit 1
fi

# Validate generated code is up to date
if ! hyper verify-generated --fail-on-outdated; then
    echo "❌ Generated code is outdated. Run 'hyper gen' to update."
    exit 1
fi

echo "✅ All HyperDev validations passed."
exit 0
```

## Pre-push Hooks

Run quality gates before pushing:

```bash
#!/bin/sh
# .git/hooks/pre-push

echo "Running HyperDev pre-push quality gates..."

# Run full quality gate suite
if ! bun run lint && bun test && bun run typecheck; then
    echo "❌ Quality gates failed. Push blocked."
    exit 1
fi

# Verify template compatibility
if ! hyper compatibility-check --remote; then
    echo "❌ Template compatibility issues detected."
    exit 1
fi

echo "✅ All quality gates passed. Push allowed."
exit 0
```

## Husky Integration

Use Husky for easier Git hook management:

```json
// package.json
{
  "husky": {
    "hooks": {
      "pre-commit": "bun run lint && lint-staged",
      "pre-push": "bun run lint && bun test",
      "commit-msg": "commitlint --edit $1",
      "post-merge": "hyper gen"
    }
  },
  "lint-staged": {
    "**/*.{ts,tsx,js,jsx}": [
      "bun run lint",
      "eslint --fix",
      "git add"
    ],
    "**/*.template.yml": [
      "hyper recipe validate",
      "git add"
    ],
    ".hyperdev/**/*": [
      "bun run lint",
      "git add"
    ]
  }
}
```

## Commit Message Validation

Validate commit messages for HyperDev conventions:

```bash
#!/bin/sh
# .git/hooks/commit-msg

commit_regex='^(feat|fix|docs|style|refactor|test|chore)(\(.+\))?: .{1,50}'

if ! grep -qE "$commit_regex" "$1"; then
    echo "❌ Invalid commit message format."
    echo "Format: type(scope): description"
    echo "Example: feat(templates): add new React component template"
    exit 1
fi

# Check if commit involves HyperDev files
if git diff --cached --name-only | grep -qE '\.(template\.yml|ejs\.t)$|^\.hyperdev/'; then
    echo "📝 HyperDev files detected in commit."
    
    # Run quick validation
    if ! bun run lint; then
        echo "❌ HyperDev validation failed for staged files."
        exit 1
    fi
fi

echo "✅ Commit message and HyperDev validation passed."
```

## Post-checkout Hooks

Sync templates after branch switches:

```bash
#!/bin/sh
# .git/hooks/post-checkout

prev_head=$1
new_head=$2
branch_switch=$3

# Only run on branch switches
if [ $branch_switch -eq 1 ]; then
    echo "Branch switched. Syncing HyperDev templates..."
    
    # Check if templates need updating
    if hyper needs-sync --quiet; then
        echo "Templates need syncing. Running sync..."
        hyper sync-templates --auto
    fi
    
    # Validate current templates
    bun run lint --quiet
    
    echo "✅ HyperDev templates synced."
fi
```

## Post-merge Hooks

Handle template updates after merges:

```bash
#!/bin/sh
# .git/hooks/post-merge

echo "Post-merge: Checking HyperDev updates..."

# Check if HyperDev files were modified
if git diff-tree --name-only HEAD@{1} HEAD | grep -qE '\.(template\.yml|ejs\.t)$|^\.hyperdev/'; then
    echo "HyperDev files were updated. Running validation..."
    
    # Validate all templates
    if ! bun run lint && bun test; then
        echo "⚠️ Template validation failed after merge."
        echo "Please resolve issues and run 'bun run lint && bun test'."
        exit 1
    fi
    
    # Update generated files if needed
    if hyper needs-regeneration --quiet; then
        echo "Regenerating updated templates..."
        hyper gen
    fi
    
    echo "✅ HyperDev post-merge validation completed."
fi
```

## Setup Script

Automate Git hook installation:

```bash
#!/bin/bash
# scripts/setup-git-hooks.sh

echo "Setting up HyperDev Git hooks..."

# Make hooks directory if it doesn't exist
mkdir -p .git/hooks

# Copy hook scripts
cp scripts/hooks/pre-commit .git/hooks/pre-commit
cp scripts/hooks/pre-push .git/hooks/pre-push
cp scripts/hooks/commit-msg .git/hooks/commit-msg
cp scripts/hooks/post-checkout .git/hooks/post-checkout
cp scripts/hooks/post-merge .git/hooks/post-merge

# Make hooks executable
chmod +x .git/hooks/pre-commit
chmod +x .git/hooks/pre-push
chmod +x .git/hooks/commit-msg
chmod +x .git/hooks/post-checkout
chmod +x .git/hooks/post-merge

echo "✅ HyperDev Git hooks installed successfully!"
```

## Package.json Scripts

Add convenience scripts for hook management:

```json
{
  "scripts": {
    "hooks:install": "./scripts/setup-git-hooks.sh",
    "hooks:test": "bun run lint && bun test && echo 'Hooks would pass'",
    "hooks:bypass": "git commit --no-verify",
    "validate:pre-commit": "bun run lint",
    "validate:pre-push": "bun run lint && bun test"
  }
}
```

Once these are in place, HyperDev validations run automatically at each stage — you don't have to think about it.
