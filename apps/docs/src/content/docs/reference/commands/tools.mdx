# hyper tools

Set up and manage linters, scanners, MCP servers, and architecture tools for your project.

```bash
hyper tools setup                    # Interactive guided setup
hyper tools setup --category ai      # Setup only AI tools
hyper tools status                   # Show current tool configuration
hyper tools add biome                # Add a specific tool
hyper tools remove snyk              # Remove a configured tool
hyper tools configure biome          # Update a tool's config
```
