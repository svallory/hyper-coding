# hyper watch

Always-on agent context monitor. Watches your codebase in real time, captures learnings, and keeps AI agents focused across sessions.

```bash
hyper watch                          # Start watching the current project
hyper watch --focus src/auth         # Watch a specific directory
hyper watch --plan payment-integration  # Scope to an active plan
hyper watch --task 42                # Focus on a single task
hyper watch --quiet                  # Suppress activity output
hyper watch --verbose                # Show all context update events
```
