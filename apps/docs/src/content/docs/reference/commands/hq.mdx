# hyper hq

Always-on Claude Code command center. Manage persistent sessions via tmux, controllable from anywhere through Remote Control and Telegram.

```bash
hyper hq start                       # Start the HQ session
hyper hq launch my-project           # Spin up a session for a project
hyper hq list                        # List available projects
hyper hq status                      # Check running sessions
hyper hq stop                        # Stop the HQ session
hyper hq stop-all                    # Tear down all sessions
hyper hq attach                      # Drop into the tmux session
hyper hq relaunch my-project         # Restart a session with --continue
hyper hq web                         # Open HQ in claude.ai/code
hyper hq config                      # View current configuration
```
