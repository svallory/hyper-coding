# Plugin Development

HyperDev is designed to be extended. If the built-in tools don't cover your workflow, you can add your own---template helpers, Claude Code integrations, quality gates, whatever fits your setup.

## Basic Plugin Development

### Creating Simple Template Helpers

You can add custom template functions with plain JavaScript---no framework needed.

```javascript
// helpers.js - Simple template helpers
export const helpers = {
  // String formatting
  capitalize: (str) => str.charAt(0).toUpperCase() + str.slice(1),
  
  // Case conversion
  kebabCase: (str) => str.replace(/\s+/g, '-').toLowerCase(),
  
  // Date utilities
  currentDate: () => new Date().toISOString().split('T')[0],
  
  // Simple pluralization
  pluralize: (word, count) => count === 1 ? word : word + 's'
};
```

Once defined, use them directly in templates:

```jig
---
to: components/{{ kebabCase :: name }}.tsx
---
// Generated on {{ currentDate }}
export const {{ capitalize :: name }} = () => {
  return <div>Hello World</div>;
};
```

### Claude Code Integration

Wire HyperDev into your Claude Code workflow via `hypergen.config.js`. Git hooks are a good starting point---they let you run validation or cleanup automatically without having to remember to do it manually.

```javascript
// hypergen.config.js - Claude Code integration
export default {
  sources: [
    { name: 'local', path: './_templates' }
  ],
  
  // Git hooks integration
  hooks: {
    'pre-commit': ['hyper gen validate'],
    'post-commit': ['hyper gen cleanup']
  }
};
```

### Basic Plugin Configuration

Here's a minimal config that enables local helpers, quality gates, and Claude Code integration:

```javascript
// hypergen.config.js
export default {
  // Local template helpers
  helpers: './helpers.js',
  
  // Quality gates
  quality: {
    syntax_validation: true,
    security_scanning: true
  },
  
  // Simple integrations
  integrations: {
    claude_code: true
  }
};
```
