## How to Use These Examples

### 1. Find Your Use Case
Browse the categories above or search for what you need. Don't overthink it---most of what you're looking for is probably in Quick Wins.

### 2. Copy and Adapt
Each example includes:
- Complete working code
- Expected output structure
- Customization instructions
- Explanation of key concepts

### 3. Test Locally
```bash
# Copy the template files to your project
# Run hyper gen to test the generation
hyper gen example-name --dry-run
```

### 4. Customize for Your Needs
- Swap out variables and prompts
- Add your own template logic
- Extend with more files
- Fit it into your existing workflow

## Example Template Structure

Every example in this library follows a consistent structure:

```
example-name/
├── template.yml          # Configuration and metadata
├── templates/            # Template files (.jig)
├── README.md            # Usage instructions
└── expected-output/     # Sample generated files
```
