# Performance Tips & Best Practices

Nothing here is going to blow your mind---these are just the habits that keep HyperDev running smoothly once your project gets bigger.

## Basic Performance Tips

### Template Caching

Repeated generation gets noticeably faster once caching is on. It's off by default, so flip it explicitly:

```javascript
// hypergen.config.js - Basic caching
export default {
  // Enable basic caching
  cache: {
    enabled: true
  }
};
```

### Large File Handling

Big projects have a way of turning slow templates into very slow templates. A few things that help:
- Keep templates simple and focused
- Break complex templates into smaller parts
- Use `--dry-run` to test before generating

## Template Best Practices

### Simple Template Design

The more a template tries to do, the harder it is to debug when something breaks. Keep them focused:

```yaml
# template.yml - Simple template configuration
name: "Basic Component"
description: "Simple component template"

variables:
  name:
    type: string
    required: true
    
files:
  - from: "component.jig"
    to: "src/components/{{ name }}.tsx"
```

### Template Organization

- Keep templates focused on single functionality
- Use descriptive names
- Include clear documentation

## Quick Tips

### Development Workflow
- Use `--dry-run` to test templates
- Keep templates version controlled
- Test with real data
- Document template usage

### Troubleshooting
If generation seems slow:
- Check template complexity
- Verify file paths are correct
- Test with smaller data sets
- Check available disk space

That covers the basics. None of this is complicated; it just takes a little discipline to stick to it as projects grow.
