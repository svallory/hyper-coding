# @hypercli/cli

The `hyper` command — a modern, scalable code generator with AI integration.

## Install

```sh
npm install -g @hypercli/cli
```

## Usage

```sh
hyper --help
hyper gen <recipe>
hyper kit install <kit>
hyper hq start
```
